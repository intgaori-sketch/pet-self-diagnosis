# 반려동물 자가진단기

반려동물의 종·품종, 기본 정보, 현재 증상을 입력하면 GPT 기반 문진 질문과 건강 참고 결과를 제공하는 웹 애플리케이션입니다.

> 이 프로젝트의 결과는 참고용 건강 정보이며 수의사의 진단이나 진료를 대체하지 않습니다. 응급 증상이 의심되면 결과를 기다리지 말고 가까운 동물병원에 연락하세요.

## 주요 기능

- 종과 품종 선택
	- 강아지, 고양이, 거북이, 토끼, 햄스터 등
	- 목록에 없는 품종은 직접 입력
- 반려동물 기본 정보 입력
	- 이름, 나이, 몸무게, 성별, 중성화 여부, 생활 환경
	- 예방접종 체크리스트
	- 과거 병력, 복용 약·알레르기, 최근 병원 방문일
- 현재 증상 기록
	- 증상 자유 입력
	- 구토, 설사, 식욕 저하, 호흡 이상 등 빠른 선택
	- 사진·영상 첨부 및 미리보기
- GPT 기반 추가 문진
	- 앞서 입력한 정보와 증상을 바탕으로 필요한 질문만 생성
	- 추가 질문이 없으면 바로 결과 분석
- AI 건강 참고 결과
	- 현재 상황 요약
	- 의심되는 상태와 판단 근거
	- 지금 취할 조치
	- 응급 신호
	- 집에서 관찰할 항목
	- 병원 방문 권고와 병원 방문 전 준비사항
	- 정보가 부족한 경우 추가 질문 또는 특정 사진·영상 요청

## 기술 구성

- Frontend: HTML, CSS, Vanilla JavaScript, Vite
- Backend: Node.js, Express
- AI: OpenAI API (`gpt-4o-mini` 기본값)
- Environment: `dotenv`

## 시작하기

### 1. 의존성 설치

```powershell
npm.cmd install
```

### 2. 환경변수 설정

`.env.example`을 복사해 `.env`를 만들고 OpenAI API 키를 입력합니다.

```powershell
Copy-Item .env.example .env
```

`.env` 예시:

```env
OPENAI_API_KEY=sk-your-openai-api-key-here
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```

실제 `.env`와 API 키는 GitHub에 올리지 마세요. `.gitignore`에서 `.env` 파일을 제외하고 있습니다.

### 3. 개발 서버 실행

```powershell
npm.cmd run dev
```

브라우저에서 `http://127.0.0.1:3000/`을 엽니다.

### 4. 프로덕션 빌드

```powershell
npm.cmd run build
```

프로덕션 모드에서는 `NODE_ENV=production`으로 실행하면 `dist` 폴더를 정적 파일로 제공합니다.

## API 엔드포인트

### `POST /api/follow-up-questions`

홈부터 증상 페이지까지의 입력을 바탕으로 추가 문진 질문을 생성합니다. AI가 필요한 질문이 없다고 판단하면 빈 질문 배열을 반환하고 바로 결과 분석으로 넘어갑니다.

### `POST /api/assessment-result`

반려동물 정보, 증상, 추가 문진 답변을 종합해 건강 참고 결과를 생성합니다. 응답에는 긴급도, 의심 상태, 근거, 조치, 응급 신호, 관찰 항목, 병원 준비사항이 포함됩니다.

## 프로젝트 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 5단계 화면 구조와 입력 폼 |

## 현재 범위와 주의사항

- 첨부 파일은 현재 브라우저 미리보기와 파일 메타데이터 전달 중심으로 동작합니다. 실제 이미지·영상 내용을 AI가 분석하려면 별도 파일 업로드 저장소와 Vision 처리 연결이 필요합니다.
- AI 결과는 의료 진단이 아니며, 질환명은 가능성 참고용입니다.
- API 키가 없거나 GPT 요청이 실패하면 안전한 기본 결과와 안내가 표시됩니다.
